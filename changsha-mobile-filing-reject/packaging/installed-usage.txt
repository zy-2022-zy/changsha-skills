长沙移动系统集团驳回数据Skill

安装完成后，在 WorkBuddy 中新建任务，搜索“长沙移动系统集团驳回数据Skill”，或输入：
“使用长沙移动系统集团驳回数据Skill，导出上一个工作日的集团驳回结果并生成 SEDP 文件。”
如果技能没有显示，请刷新技能列表或重新打开 WorkBuddy。

安装包内置 Node.js 和程序依赖，无需安装 Node.js、npm 或 pnpm。

浏览器支持两种方式：
- 云浏览器：在技能目录的 .env 中配置 BROWSER_CDP_URL，例如本地 SSH 隧道地址 http://127.0.0.1:19222。此模式不要求本机安装 Chrome 或 Edge。
- 本地浏览器：BROWSER_CDP_URL 留空，电脑需要安装 Chrome 或 Microsoft Edge。

云浏览器首次登录或会话过期时，由 Agent 调用分阶段登录命令，员工不需要打开 noVNC：`login-start` 自动填写手机号并识别协议复选框；如页面要求计算/人机验证，Agent 将题目转发给员工，员工在聊天窗口提供答案后调用 `login-verify --answer <答案>`；随后 Agent 询问短信验证码，并通过标准输入调用 `login-submit --sms-code-stdin` 自动填写和提交。程序不自动破解或绕过人机验证；短信验证码不写入日志、配置或状态文件。任务结束只断开自动化连接，不关闭云浏览器或当前标签页。noVNC 仅用于故障排查。下载文件保存到运行 Skill 的电脑。
本地浏览器模式继续使用本机登录缓存。云浏览器模式不会把云端 Cookie 或会话信息复制到本机。

文件默认保存在 D:\报备\集团驳回\查询日期\，目录不存在时自动创建。
没有 D 盘的电脑可以在安装向导里选择其他目录。
生成的 SEDP 文件固定四列：子端口、签名、报备结果、备注。
签名留空，报备结果为“失败”，备注为“集团驳回”。

本机配置在技能目录的 .env，可在这里设置 LOGIN_PHONE、DOWNLOAD_DIR、BROWSER_CDP_URL；仅本地浏览器模式需要设置 BROWSER_CHANNEL。
安装包不包含开发电脑的手机号、登录会话、历史导出结果。不要把 .env 或 .runtime 分享给他人。
升级保留已有的 .env、.runtime 和 reports；卸载保留本机配置及业务数据。

手动检查计划（在技能目录运行）：
scripts\run.cmd export --date 2026-11-05
实际执行：
scripts\run.cmd export --date 2026-11-05 --execute
续查：
scripts\run.cmd results --date 2026-11-05

以上日期仅为命令示例，请替换为实际查询日期。
WorkBuddy MCP 交互登录（开发联调）：
- 技能源码目录运行 pnpm install --frozen-lockfile，并在该目录配置本机 .env 中的 LOGIN_PHONE、BROWSER_CDP_URL。
- WorkBuddy MCP Server 配置使用 stdio，命令 pnpm，参数 run mcp，工作目录为技能源码目录。
- Agent 通过 login_start 获取并展示图形验证码图片，用户回复后调用 login_verify_captcha；再询问短信验证码并调用 login_submit_sms。
- 当前版本使用单个云浏览器会话，只支持单员工串行联调。详细配置见技能目录中的 SKILL.md「WorkBuddy MCP 交互登录」。
